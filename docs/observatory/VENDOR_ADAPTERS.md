# Optional blinded decision-model adapters

Jev and OpenAI Decisions use the #72 frozen inference interface and append immutable classification runs. Both are disabled by default and abstain when keys/enablement/budget are absent. They receive only four signal values and missingness; no source IDs, cohort labels, provenance strings, confidence, session IDs, run tags, authority outcomes or generation prompts are transmitted. The trusted, versioned classification question/prompt is stored separately from experiment generation. Scores are unvalidated execution hypotheses, not demonstrated calibrated accuracy, eligibility or authority.

Official contracts checked 14 October 2026: [TypeSafe](https://docs.typesafe.ai/api) uses `POST /v1/systemone` with a `noul` question; [OpenAI Decisions](https://developers.openai.com/api/reference/resources/decisions/methods/create) uses `POST /v1/decisions` with a `predicate` question. Their response shapes differ and are validated independently, including refusal, schema/model changes and out-of-range scores. Requests have a fixed HTTPS endpoint, no redirects, a 4096-byte body limit and five-second timeout. No retries are automatic: retry/rerun requires another explicit request and consumes another reservation. Raw vendor responses/errors and secret keys are not persisted or logged.

For a separately approved synthetic run, configure `TYPESAFE_API_KEY` or `OPENAI_API_KEY`, then the corresponding `OBSERVATORY_JEV_*` or `OBSERVATORY_OPENAI_*` settings: `ENABLED=true`, `MODEL`, `DAILY_CALLS`, `DAILY_MICRO_USD`, `RESERVATION_MICRO_USD`, `MIN_INTERVAL_MS`. Daily request limit is capped at 1000; daily reservation limit at USD100; minimum interval at 100ms. **These are maximum configurable ceilings, not default permissions or approved spending.** Defaults make no calls.

Before enabling, verify current provider pricing and choose a conservative upper cost per bounded request in integer micro-USD. PostgreSQL atomically reserves that amount and a call before outbound work, enforcing a UTC-day budget and rate interval across replicas. Failed calls are not refunded. Actual billed cost remains unknown in results. The reservation cap bounds configured reservations, not a contractual guarantee against provider price/token-accounting changes; keep a provider-account hard spend limit as the billing backstop. Missing verified pricing/budget means leave adapters disabled.

`classifier: "jev"` or `"openai-decisions"` selects an adapter in the existing classification endpoint. The default Jev request pins `jev-1.13.0`; OpenAI currently documents `gpt-6-luna`. Returned model IDs must match the requested pin; aliases that resolve differently deliberately fail rather than silently rewrite provenance. A future API/model update needs a contract/version update and fresh comparison evidence.

Tests use intercepted synthetic responses only. No paid/live call, real vendor acceptance or comparative accuracy is established by this delivery. A genuine same-holdout vendor comparison and provider cost/latency evidence remain required before completing #74's research acceptance.
